# 📚 Literatura

Notas de literatura basadas en papers, libros y artículos. Principalmente importadas desde **Zotero**.

## Subcarpetas

- **Papers/** — Artículos científicos y preprints
- **Libros/** — Notas de capítulos o libros completos
- **Revisiones/** — Reviews y surveys del campo

## Integración con Zotero

Las notas importadas desde Zotero se guardan aquí usando la plantilla `07 - Plantillas/Plantilla - Paper.md`.

> [!NOTE]
> Usa el plugin **Zotero Integration** de Obsidian para importar directamente.
