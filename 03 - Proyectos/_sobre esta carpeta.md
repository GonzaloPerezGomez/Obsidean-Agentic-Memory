# 🚀 Proyectos

Proyectos activos de investigación, trabajos académicos y tareas en curso.

Cada proyecto tiene su propia subcarpeta con toda la documentación asociada.

## Estructura de un proyecto

```
Nombre del Proyecto/
├── README.md          # Descripción y objetivos
├── Notas/             # Notas específicas del proyecto
├── Resultados/        # Outputs y resultados
└── Referencias/       # Papers y recursos relevantes
```
